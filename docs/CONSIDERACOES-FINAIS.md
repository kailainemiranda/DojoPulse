# Considerações finais

Durante o desenvolvimento do DojoPulse, uma das principais dificuldades foi transformar as necessidades de uma academia de artes marciais em uma plataforma simples, organizada e fácil de utilizar. Foi necessário planejar a navegação, definir as telas de cadastro e login e organizar as informações sobre turmas, professores, horários, graduações e avisos.

Outro desafio foi criar diferentes níveis de acesso para administradores e alunos. O administrador consulta os cadastros realizados, enquanto o aluno visualiza somente as informações relacionadas às atividades da academia. Essa separação ajudou a compreender a importância da organização das funcionalidades e do controle de acesso em uma aplicação web.

Durante o projeto, foram aplicados conhecimentos de HTML, CSS e JavaScript. O desenvolvimento da identidade visual, da responsividade e das interações entre as telas possibilitou colocar em prática conteúdos estudados ao longo do curso. O uso do `localStorage` permitiu criar uma versão demonstrativa sem a necessidade de um banco de dados externo.

A publicação no GitHub Pages também foi importante, pois tornou possível disponibilizar a aplicação gratuitamente na internet. Como evolução futura, o projeto poderá utilizar uma API, banco de dados real, autenticação segura, recuperação de senha e backups.

De modo geral, o DojoPulse uniu planejamento, programação e design em uma solução voltada para uma necessidade real. O projeto reforçou a importância de compreender o público, organizar as informações e desenvolver uma interface acessível para apoiar as atividades de uma academia de artes marciais.
