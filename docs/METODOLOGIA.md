# Metodologia

O projeto foi desenvolvido em etapas. Primeiro foram definidos o tema, o público e as necessidades da academia. Depois foram planejadas as telas de apresentação, cadastro, login e atividades.

A estrutura foi criada com HTML5. Em seguida, foi aplicada a identidade visual com CSS3, utilizando layout responsivo, fundo escuro e cores neon. Por último, o JavaScript foi utilizado para controlar a navegação, os formulários, a autenticação local, os perfis de acesso e a área administrativa.

Após o desenvolvimento, foram realizados testes de cadastro, login, acesso administrativo, troca de telas e visualização em diferentes tamanhos de tela. Ao final, os arquivos foram documentados e publicados no GitHub Pages.

O fluxograma completo está em [metodologia-dojopulse.svg](../metodologia-dojopulse.svg).
