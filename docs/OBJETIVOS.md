# Objetivos

- Desenvolver uma plataforma web responsiva para um projeto social de artes marciais.
- Permitir o cadastro de participantes interessados nas atividades da academia.
- Separar o acesso entre administradores e alunos.
- Disponibilizar informações sobre turmas, professores, horários, graduações e avisos.
- Permitir que administradores consultem os cadastros realizados.
- Organizar as atividades em uma interface moderna e de fácil utilização.
- Publicar a aplicação gratuitamente no GitHub Pages.
